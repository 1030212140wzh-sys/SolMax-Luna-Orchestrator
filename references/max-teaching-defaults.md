# Max Teaching Defaults

Load only for Max's teaching-material tasks when the latest user instruction does not override these habits.

## Deliverable bias

- Prefer finished usable artifacts over abstract advice.
- If the user asks for PDF, deliver the actual PDF rather than only LaTeX/source code unless source is also requested.
- Keep original or user-specified filenames, especially Chinese filenames, where practical.
- Do not add unrequested labels such as `AI generated`, `ChatGPT`, `non-official`, `sample version`, `transition version`, or similar meta text.
- Materials should look like normal teacher-created resources rather than an AI poster.

## Teaching architecture

For substantial notes, prefer a coherent progression such as:

`prerequisite recap → concept/definition → intuitive meaning → derivation/explanation → standard example → important variants → common mistakes → summary → practice`

For important worked examples, use when useful:

`original question → translation/interpretation → what is tested → overall idea → detailed steps → final answer → faster valid method → common mistakes → pattern recognition`

Do not force every heading into small exercises.

## Explanation depth

Default assumption: the student may have ordinary or shaky foundations unless the user says otherwise.

- Do not hide the key bridge with `obviously`, `similarly`, or `clearly`.
- Explain new abstract terminology in plain language before or alongside the formal definition when useful.
- Detailed means no critical skipped step, not unnecessary repetition.
- Keep mathematical transformations visually separated enough to follow.

## Mathematics

Check carefully:

- exponent hierarchy;
- brackets;
- logarithms;
- roots;
- signs;
- fractions;
- domain/range restrictions;
- inequality direction;
- ± cases;
- exact vs approximate values;
- units/significant figures where relevant.

For handwritten/photographed expressions, verify transcription before solving.

## Physics

For calculations, use when useful:

`Known → Find → Principle → Substitute → Unit → Answer`

For qualitative questions, explain the causal chain rather than only listing marking keywords. Distinguish a formula to memorize from the physical reasoning behind it.

## Exam-board discipline

For A-Level/CIE/Edexcel/AP/IB/DSE/IGCSE/SAT/TMUA/AMC/BPhO and similar systems:

- keep the correct board/course scope;
- verify current official syllabus/specification when uncertain or time-sensitive;
- do not silently mix boards;
- do not add extension material unless requested.

## Difficulty

When the user asks for harder material, increase reasoning depth, linked steps, transformations and exam-style traps. Do not merely use uglier numbers.

Avoid unnecessary duplicate questions. Each repeated practice item should add a meaningful variation.

## Student edition

- Same canonical question set as teacher edition.
- No answer leakage.
- Adequate working space.
- Clear numbering and paragraph labels.
- Long-response questions get enough answer space.

## Teacher edition

- Same question IDs/order as student edition.
- Correct answers and sufficiently detailed solutions.
- Teaching notes, common errors and faster valid methods where useful.

## Visual defaults

Unless the current task specifies otherwise:

- white background;
- professional teaching-document look;
- clear title hierarchy;
- readable body size and spacing;
- formulas given breathing room;
- restrained light accents;
- no large dark blocks;
- no unnecessary gradients;
- no childish decoration;
- avoid excessive information density.

For iPad-first material, slightly more spacing and restrained color can be used because printing is not the primary constraint.

## Artifact QA

Before delivery check as relevant:

- file opens;
- page count plausible;
- fonts/glyphs correct;
- formulas not clipped;
- images legible;
- tables inside bounds;
- no text overlap;
- no abnormal blank pages;
- headings/page breaks sensible;
- question/answer numbering correct;
- paired versions consistent.
